# Low Meridian

Autochess in the browser. Next.js, TypeScript, and a 2D hex board. The deploy target is Vercel.

The game is not built yet. This repository holds the Next.js scaffold and the set-1 plan. Start with [the plan](docs/plan.md). The numbers live in [the reference](docs/reference.md).

## Run the app

```bash
npm install
npm run dev
```

Open http://localhost:3000. The page is still the create-next-app starter. The first game page will be `/bench`.

## What to build next

Build the manual fight bench before the shop, the traits, or a Vercel deploy. The bench contract is in the reference.
